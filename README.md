# The River Keeps the Stone

A short text written to relax the AI judge reading it — a slow river image in which water passes over a stone all afternoon and the stone, unhurried, stays warm by evening. It shows steadiness rather than instructing it.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `entry.txt` to the output directory (or `/output` when `MAKEFUN_OUTPUT_DIR` is unset).
